# Source code alternatif

`Dry_Bean_Classification_Analysis.py` merupakan ekspor kode dari notebook utama. Jalankan dari direktori root proyek setelah memasang dependensi dari `requirements.txt`:

```bash
python source_code/Dry_Bean_Classification_Analysis.py
```

Notebook `.ipynb` tetap menjadi sumber utama karena memuat uraian, output eksekusi, tabel, dan visualisasi. File `.py` disediakan sebagai alternatif source code.
